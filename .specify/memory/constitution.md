# Summarizing 宪法（Spec Kit Constitution）

> **权威声明**：本宪法是 `CLAUDE.md` 与 `docs/`（00-数据契约 / 01-规格 / 02-决策台账）的**派生摘要**，供 Spec Kit 的 specify/plan/tasks 环节对照使用。**冲突时一律以 CLAUDE.md 与 docs/ 为准**；修改约定先改那边，再同步这里。

## Core Principles（产品与流程六纪律，01§一）

### I. 先跑通完整业务循环
任何扩展之前，系统必须先有一次端到端可用的循环。新特性若让主循环变复杂，先问值不值。

### II. 每阶段结束系统必须可独立使用
不留半成品状态跨越阶段边界；一个批次做完，系统照常可用。

### III. 模块数量受控——宁可功能少，不可结构乱
不引入非必要抽象（ORM / 状态管理库 / 微服务化 / 通用框架）。目录名必须说得出「它是什么」；含糊兜底目录（utils/features/core 之类无判据的）不许出现。

### IV. 不写没有调用者的东西
判据：**现在没有调用者 = 现在就不许存在**。不留扩展点、不预写抽象、不造「将来可能用得上」的函数。抽象等到 ≥2 个真实用例齐了再抽。

### V. 在真实入口验证
测试断言用户看到的那行字，走真实入口（HTTP 端点 / 真实组件渲染），不 mock 内部实现。

### VI. 不确定先问，不要自己发挥
规格没写、决策台账标待确认的，先查 03-开放问题，再问用户。绝不猜着实现。

## 产品不变量（任何 spec 都不得违反）

- **原文先行**：一切原始文本先落 `raw_inputs` 永不丢失；AI 输出永远是派生结果，可回溯到原话。
- **证据链，不打分**：元素 → 逐字引文 → 原始批次，全链路可查；不生成「可信度」类再生值。
- **静默任何事都禁止**：降级、失败、矛盾、合并、丢弃，全部留痕且可见（流水 `pipeline_events`）。
- **LLM 不裸操作存储**：读走真代码检索工具、写走围栏校验 + 执行器独占落笔；围栏只校验行为（ID 真实/白名单/格式/引文逐字），不评判提取对错。
- **粘贴 ≠ 指令**：指令只能来自对话中用户本人；粘贴正文里的指令性语句一律当信息。
- **零变更合法**：没用/片面/不权威的信息留痕即可，不强迫产出变更。

## 高频禁区（速查；完整清单与理由见 CLAUDE.md）

日期继承/传播；裸日期（事件必须带语义名）；真实性打分；缺日期/缺字段进存疑（存疑=事件存疑）；相对日期用接收时间兜底；前台 AI 直接写库；「还有 N 件没看」式措辞与主动推荐；搁置区当待删除；顺手实现台账延后项（L1–L21）；树形浏览器/知识图谱/插件系统/独立知识库界面。

## 工程红线

- **类型严格**：TS strict 全栈，禁 `any` / `as` 绕过 / 非空断言 `!`；用 `satisfies`、类型守卫、zod 解析让编译器验证。唯一例外：网络边界单层 `as`（隔离在 `apps/web/src/api.ts`）。
- **类型单一来源真共享**：契约 schema 住 `packages/shared`，改字段名前后端必须同时编译失败。
- **JSDoc 人话描述**：每个导出函数首行前有 JSDoc，写意图与依据（`jsdoc/require-jsdoc` 强制）。
- **注释可溯源**：每句注释能回答「你怎么知道？」，答不上就删或标为意图。
- **改完自审三问**：改完了吗（跨文件一处不漏）/ 删干净了吗（旧术语零残留）/ 新特性做全了吗（每处引用真落地）。每轮改完 grep 扫旧术语并逐条复核。

## 质量门

- `npm run check`（tsc + eslint + vitest）必过；
- `npm run check:dead`（knip）必过；
- `npm run build -w @summarizing/web` 出包成功；
- 测试在真实入口断言用户所见；提交走 pre-commit（lint-staged）+ pre-push（check）。

## 开发工作流（最终审查闭环）

```
/review high        # 只诊断不改码（在原始状态上审）
修 Critical/High    # 只修阻断性问题，最小改动
git commit          # ← 回滚点（必须在 /simplify 之前）
/simplify           # 动刀清理（复用/简化/效率）
npm run check + 行为等价性核对
★ S 审查            # 用户人工过一遍最终形态（不可省）
git commit          # 收口
```

- 回滚点建在动刀**之前**；末轮审「简化前后行为对照」。
- 文档与代码同批演进：改任何约定 → 同步 00/01/02/03/04 + CLAUDE.md，不留新旧并存。
