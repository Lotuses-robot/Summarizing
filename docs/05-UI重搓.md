## 五、设置面板

**原则：用户偏好进设置，系统策略进代码。**
**布局（用户 2026-09-27 定；走查修订③ 2026-09-30 重排）**：左侧分类栏（外观/AI/数据/信源）+ 右侧**分组卡**（macOS 系统设置式：外观/AI/数据每类一张圆角卡、**信源为每源一张**，**卡内一行一设置——左标签(+灰描述)、右控件对齐成列**，footnote 在卡下方灰小字），点左侧平滑定位到右侧分区。
**交互总则（走查修订③）：改完即生效——下拉/开关/色板点一下即存，输入框失焦即存；卡尾状态行一闪「已保存」、失败常驻红字（不静默；按字段键存，不被别的成功顶掉；外观区无提示——localStorage 不会失败）；整页无「保存」按钮；关闭前先 blur 落一次（含 Esc 路径）**（这也是「保存不自然」的根治）。

- **外观**（localStorage；改完即生效）：主题（亮/暗/系统，分段控件）· 主题色（色点）· 字体（分段控件）· 信息密度（分段控件）· 记忆项（对话面板开合、段折叠——卡下 footnote）
- **AI**（存 SQLite `app_settings`；行式分组卡）：
  - baseURL / 模型 / API Key（掩码）三行输入，**失焦即存即热切换（不重启）**；Key 留空 = 沿用现值
  - **测试连接**行：发最小请求实测通/断与延迟；「清除覆盖」同在行尾（覆盖生效时显示）
  - 优先级 **设置 > .env**（.env 仅作首次种子）；提供「清除覆盖」回到 .env
  - ⚠️ 明示：Key 本地明文存 SQLite（本地单机，知情选择）
  - ❎ **提示词不进设置**（2026-09-30 用户拍板）：提示词是系统策略（行为契约的一半），住代码里——要调改 `agent0/prompt.ts` / `agent0/sweep.ts` / `chat.ts`
- **数据**：一行式——数据文件路径说明 + 行内「下载备份」按钮（服务端在线备份 → 浏览器下载 `summarizing.db`）
- **信源**（D-89 真界面；走查修订③ 改完即生效）：`GET /api/sources` 拿 `[{name, state, lastError?, lastOkAt?, settings: schema}]`——**每源一张分组卡**（卡头 = 源名 + 状态章，`state === "error"` 时显示「最近出错」），**按 schema 渲染通用表单**（前端不含信源专属知识）：text/number/boolean/secret 各按型渲染，select 下拉，**record = 键值对行编辑**（加行/删行）；**失焦即存**（与已存值不同才发 `PUT /api/sources/:name/settings/:key`）；**清空数字输入 = `DELETE` 该键 = 回适配器默认**（即时生效）；行内一闪「已保存」，失败常驻红字。
